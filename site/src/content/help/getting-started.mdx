## Creating an account

Sign up with an email and password from the app's sign-up page. You'll get a verification email — following that link confirms your address and unlocks email-based sharing (collaborators are matched by verified email address).

## Asking your first question

From your dashboard, create a new canvas and type a question into the prompt box — anything from basic arithmetic to a full geometry problem. openmaths picks a default model automatically; you can change it per-question from the model picker if you want.

## Reading the answer

Depending on the question, you'll get one or more of:

- **Step-by-step solution** — numbered steps, each expandable for a "why?" explanation of that specific step.
- **A diagram** — for geometry, graphing, and similar visual questions, drawn on the canvas next to the answer.
- **A table** — for comparison or data-organization questions.

Not every question gets a diagram — see [how narration and voice playback work](/help/narration-and-playback) for how the diagram and voice work together once one exists.

## The canvas itself

Every question is a node on an infinite canvas, not a line in a chat log. You can drag nodes around, zoom out to see everything at once, and — most importantly — branch a follow-up question off any existing answer instead of losing context in a linear thread.
