Most questions still get one focused answer — solution steps, a diagram, or a table, whichever fits. But some questions genuinely need more than one at once, so answers can now include several forms together when the question calls for it: a diagram *and* a comparison table, for example, instead of forcing everything into one format.

This is additive — the existing single-form answer path is unchanged and still the default whenever one form is enough.
